How it works

  1. GET /siri_vehicle_locations/list with Jerusalem bbox + time window (CORS: *, no key).
  2. Drop GPS errors (velocity > 100 km/h).
  3. Road mode: fetch OSM streets from Versatiles vector tiles at zoom 14 (Overpass-independent; zoom 13 drops minor streets), project each point to the nearest segment within 35 m, split ways into ≤60 m pieces, average per piece.
  4. Grid mode: average per ≈110 m cell — same idea as the API's own /siri_velocity_aggregation endpoint, but time-bounded client-side.

This is a nearest-segment snap, not full trajectory map-matching (no route/HMM inference). Averages include dwell time at stops unless you untick “include stopped”.

Data: Open Bus Stride API (Hasadna, SIRI via Israel MOT) · Roads/basemap © OpenStreetMap contributors, streets via Versatiles.
